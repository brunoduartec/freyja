# Checklist de qualidade — Relevo da encosta oeste

**Spec** [Relevo da encosta oeste](../spec.md)

- [x] A proposta identifica o problema e o trecho da primeira avaliação.
- [x] As medições atuais e o perfil esquemático estão identificados.
- [x] Os critérios cobrem as duas vistas, o percurso, a praia e os acessos.
- [x] O papel das pedras é tratado como decisão visual após o estudo do relevo.
- [x] A spec está pronta para avaliação do usuário.
