# Checklist de qualidade da especificação de corrida e salto

**Data** 19/11/2026  
**Entrega** [Especificação](../spec.md)

## Qualidade do conteúdo

- [x] Descreve comportamentos sem prescrever detalhes de implementação.
- [x] Foca nas ações e nos resultados para o jogador.
- [x] Usa linguagem acessível.
- [x] Inclui as seções obrigatórias.

## Completude dos requisitos

- [x] Registra as propostas sem deixar marcadores de esclarecimento.
- [x] Os requisitos podem ser testados.
- [x] Os resultados são observáveis e têm condições de verificação.
- [x] Os critérios independem da tecnologia usada.
- [x] Os cenários de aceitação cobrem corrida e salto.
- [x] Os casos de borda identificam entrada repetida, colisão, queda e suspensão dos controles.
- [x] O escopo é delimitado à locomoção do protagonista na cena principal.
- [x] As premissas e dependências estão registradas.

## Prontidão

- [x] Os comportamentos têm condições de aceitação.
- [x] Os cenários cobrem os fluxos principais.
- [x] Os critérios permitem avaliar a entrega em jogo.
- [x] A especificação permanece independente da implementação.
