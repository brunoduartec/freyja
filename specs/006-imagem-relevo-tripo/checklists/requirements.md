# Checklist de qualidade da imagem do relevo

**Data da revisão** 2026-11-13  
**Proposta** [Imagem do relevo para o TripoAI](../spec.md)

- [x] Objetivo, público, fonte e entrega estão definidos em linguagem direta.
- [x] Os requisitos descrevem o resultado visual e cada requisito tem um critério de aceitação verificável no PNG.
- [x] A comparação visual cobre silhueta, principais volumes e enquadramento.
- [x] As premissas cobrem as superfícies encobertas e as escolhas de isolamento do terreno.
- [x] O escopo termina na imagem e está pronto para avaliação do usuário.
