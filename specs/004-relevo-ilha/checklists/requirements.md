# Checklist de qualidade — Relevo da ilha

- [x] A referência visual e o objetivo da entrega estão identificados.
- [x] Os cenários de avaliação e caminhada estão descritos.
- [x] Os requisitos e critérios são verificáveis.
- [x] Os limites da casinha isolada e das demais casas estão explícitos.
- [x] A parte não visível na referência está identificada como interpretação.
- [x] Dependências, segurança da navegação e recuperação estão descritas.
- [x] Toda a superfície terrestre caminhável, incluindo o monte, está explicitamente coberta.
- [x] Não há questões bloqueantes para planejar após aprovação do usuário.
