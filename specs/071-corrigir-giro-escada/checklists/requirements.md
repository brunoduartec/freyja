# Checklist da especificação

- [x] Comportamento apresentado do ponto de vista do jogador.
- [x] Cenários principais de giro, colisão, pausa e retomada cobertos.
- [x] Critérios observáveis, com repetições e evidência visual.
- [x] Casos de borda, escopo e premissas registrados.
- [x] Aviso de câmera registrado como observação a verificar.
