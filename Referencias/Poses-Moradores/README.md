# Poses dos moradores

São 27 PNGs individuais em pose A, agrupados pelas casas B1–B4, A1–A4 e L1–L4. Artur Marçal, Teresa Faria e Bento Nogueira estão com os três visitantes em [Poses-Cais](../Poses-Cais/).

As imagens são referências para modelagem no Meshy. A meta de cerca de 3 mil triângulos se refere à malha final e deve ser conferida no Blender.
