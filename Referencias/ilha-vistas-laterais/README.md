# Vistas laterais de referência

Estas quatro imagens foram geradas em 2026-11-12 a pedido do usuário, usando `../ilha-vista-topdown-004.png` como referência de planta. Arquivos: [norte](vista-norte.png), [sul](vista-sul.png), [leste](vista-leste.png) e [oeste](vista-oeste.png).

Por decisão do usuário, a imagem top-down, a perspectiva aérea e estes quatro perfis são referências mandatórias de exatidão para as respectivas vistas. Criar capturas ortográficas reais de todas as vistas no modelo 3D e comparar com cada imagem. Se as referências entrarem em conflito em alguma região, registrar e resolver o conflito com o usuário antes de aprovar essa parte do relevo.

Estes perfis foram gerados como imagens conceituais, não como renders de uma malha 3D nem medidas extraídas de uma planta. Sua adoção como referência mandatória não transforma pixels em cotas: fidelidade significa reproduzir as formas visíveis nas vistas correspondentes.
